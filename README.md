# Конспекти ВОС-420

## Структура

- `index.html` — головна сторінка, вибір тем і налаштування вікторин.
- `style.css`, `site-ui.js`, `asset-version.js` — спільне оформлення, поведінка сторінок і версія ресурсів.
- `themes/<тема>/` — конспект `index.html`, банк `questions.json`, згенерований `quiz-data.js` та зображення в `images/`. Теми без вікторини не мають банку питань.
- `quiz-engine/` — сторінка вікторини, рушій, запуск, завантаження банків, статистика та її перенесення.
- `search/` — пошук, пошук у темі та згенерований індекс `index.js`.
- `glossary/` — сторінка глосарія, терміни `data.js`, пошук і підказки в конспектах.
- `admin/` — локальний редактор питань і сервер із доступом до файлів.
- `scripts/` — збірка та форматування згенерованих даних.
- `tests/` — перевірки редактора, банку ТСП, статистики й локальних посилань.

## Редагування та перевірка

Команди виконуються з кореня проєкту після `npm install`:

```sh
npm run build
npm run format:check
npm run test:admin
npm run test:statistics
npm run test:paths
```

Питання редагують у `themes/<тема>/questions.json`; після змін запускають `npm run build`. Файли `quiz-data.js`, `search/index.js` та `asset-version.js` генеруються автоматично.

Локальний редактор запускається командою `npm run quiz:admin`: <http://127.0.0.1:8769/admin/>. Докладніше — [інструкція редактора](admin/README.md).

Сайт можна відкривати з `index.html` або розміщувати на статичному сервері. Старі адреси до реорганізації каталогів не підтримуються.
