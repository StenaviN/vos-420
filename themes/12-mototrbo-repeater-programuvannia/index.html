Порядок налаштування

У CPS 2.0 налаштуй ретранслятор, а для роботи через мережу IP Site Connect — також канали й роумінг абонентських радіостанцій.

  1. Задай псевдонім та ID ретранслятора.
  2. Налаштуй RAS і, за потреби, перевірку діапазонів ID радіостанцій.
  3. Задай параметри каналу: назву, колірний код і частоти.
  4. Для IP Site Connect визнач роль ретранслятора та мережеві параметри.
  5. На радіостанціях налаштуй список роумінгу й признач його потрібним каналам.

Базові операції читання та запису конфігурації описані в конспекті програмування MOTOTRBO.

Псевдонім та ID ретранслятора

ЗагальнеЗагальні параметри

Заповни поля «Псевдонім радіо» та «ID радіопристрою». Ці параметри задають як для окремого ретранслятора, так і для кожного вузла IP Site Connect.

Захист доступу RAS

ЗагальнеБезпекаОбмежений доступ до системи (RAS)

Увімкни «Автентифікація» та введи узгоджений ключ RAS. За ввімкненої автентифікації ретранслятор застосовує ключ для обмеження доступу; за вимкненої ключ не застосовується.

RAS керує доступом до ретранслятора. Налаштування шифрування AES-256 на радіостанціях виконується окремо.

Перевірка діапазонів ID радіостанцій

Як додатковий захист увімкни «Перевірка діапазону ID радіопристрою». Додай діапазон і вкажи мінімальний та максимальний ID. За потреби створи декілька діапазонів.

Канал ретранслятора

Призначення зон/каналівЗонаКанал

Відкрий канал і заповни назву каналу, колірний код, частоту приймання RX та частоту передавання TX.

Червоний або помаранчевий індикатор

ЗагальнеЗагальні параметриТип сигналізації

Якщо перший індикатор ретранслятора світиться червоним або помаранчевим, перевір призначення сигналізації:

  • Червоний: зверни увагу на поля зі значенням «Головний».
  • Помаранчевий: перевір поля зі значенням «Другорядний».

Ці значення стосуються типу сигналізації, а не ролі ретранслятора в IP Site Connect.

Роумінг: підготовка каналів радіостанції

Ці дії виконуються в конфігурації абонентської радіостанції. Спочатку мають бути створені канали й введені ключі RAS.

Призначення зон/каналівЗона

На каналах для роботи з ретрансляторами встанови позначку «Під’єднання до вузла IP».

Створення списку роумінгу

Списки скануванняСписок роумінгу
  1. Створи новий список або відредагуй старий, якщо він більше не потрібний у попередньому вигляді.
  2. Задай назву списку.
  3. Додай потрібні канали з лівої колонки до правої.

Автоматичний і ручний роумінг

Автоматичний роумінг

Списки скануванняРоумінг

Увімкни «Пошук активного вузла».

Ручний роумінг

ЗагальнеКнопки керування

Признач кнопкам функції «Ручний роумінг вузлів» і «Блокування вузла увімк/вимк».

Призначення списку каналам

Призначення зон/каналівЗонаКанал

Повернися до потрібного каналу. У полі «Список сканування/роумінгу» обери створений список за його назвою.

IP Site Connect: головний та одноранговий вузли

Спочатку налаштуй головний ретранслятор, потім однорангові. Для кожного задаються власні ID, псевдонім і мережеві параметри.

Параметр Головний Одноранговий
Тип каналу Головний Одноранговий
Ключ автентифікації Надає організатор зв’язку Такий самий, як на головному
Головна IP-адреса За параметрами організатора зв’язку Ethernet IP-адреса головного ретранслятора в наведеній схемі
Мережеві параметри Відповідно до маршрутизатора, підключеного до конкретного ретранслятора

Числа на знімках — приклади конфігурації. Адреси та ключ автентифікації використовуй згідно з параметрами своєї мережі.

Головний ретранслятор

1. Ідентифікація

ЗагальнеЗагальні параметри

Задай ID та псевдонім ретранслятора.

2. Зв’язок між вузлами

ЗагальнеВстановлення зв’язку

У полі «Тип каналу» вибери «Головний». Заповни «Ключ автентифікації» та «Головна IP-адреса» за параметрами, наданими штабом, що організовує зв’язок.

3. Мережа

ЗагальнеМережа

Для «Швидкість з’єднання» вибери «Автоматичне узгодження». Параметри «IP-адреса Ethernet», «IP-адреса шлюзу» та «Маска мережі шлюзу» задаються відповідно до маршрутизатора, підключеного до цього ретранслятора.

4. Доступ RAS

ЗагальнеБезпека

Введи ключ RAS для доступу радіостанцій до ретранслятора.

5. Канал

Призначення зон/каналівЗонаКанал
  • Задай колірний код.
  • У полі «Під’єднання до вузла IP» вибери тайм-слот, який працюватиме в мережі.
  • Налаштуй поріг RSSI; у матеріалі рекомендовано виконувати це через програму RDAC.
  • Задай частоти приймання й передавання.

Одноранговий ретранслятор

1. Ідентифікація

ЗагальнеЗагальні параметри

Задай ID та псевдонім ретранслятора.

2. Зв’язок між вузлами

ЗагальнеВстановлення зв’язку

У полі «Тип каналу» вибери «Одноранговий». Вкажи той самий ключ автентифікації, що й на головному. У наведеній схемі «Головна IP-адреса» — це значення «IP-адреса Ethernet» головного ретранслятора.

3. Мережа

ЗагальнеМережа

Для «Швидкість з’єднання» вибери «Автоматичне узгодження». Параметри «IP-адреса Ethernet», «IP-адреса шлюзу» та «Маска мережі шлюзу» задаються відповідно до маршрутизатора, підключеного до цього ретранслятора.

4. Доступ RAS

ЗагальнеБезпека

Введи ключ RAS для доступу радіостанцій до ретранслятора.

5. Канал

Призначення зон/каналівЗонаКанал
  • Задай колірний код.
  • У полі «Під’єднання до вузла IP» вибери тайм-слот, який працюватиме в мережі.
  • Налаштуй поріг RSSI; у матеріалі рекомендовано виконувати це через програму RDAC.
  • Задай частоти приймання й передавання.

Random Key: випадковий ключ AES-256

Це налаштування абонентської радіостанції. Для подальшої роботи використовуй AES-256; 40-бітний ключ не рекомендований.

1. Дешифрування

ЗагальнеБезпекаЗагальне

Зніми позначку «Виправлено дешифрування ключа захисту конфіденційності».

На знімку також видно старі поля посиленої конфіденційності. Для AES-256 ключі вводяться в розділі «Симетричний», як показано нижче.

2. Ключі

ЗагальнеБезпекаСиметричний

Натисни «+» і введи ключі AES-256: мінімум 2, максимум 32.

3. Вибір на каналі

Призначення зон/каналівКаналСиметричний псевдонім

Вибери «Випадково». Пов’язані параметри AES-256 наведені в налаштуваннях шифрування каналу.
