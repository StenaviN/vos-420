# Локальний редактор вікторин

У корені проєкту виконайте `npm run quiz:admin` і відкрийте **http://127.0.0.1:8769/admin/**. Потрібен Node.js 20 або новіший; додаткові пакети не потрібні. Для іншого порту задайте змінну середовища `QUIZ_ADMIN_PORT`. Зупинка сервера — Ctrl+C.

На локальних сторінках головного меню та вікторини цей сервер додає кнопку «Редактор питань». Звичайний статичний сайт не має доступу до API запису. На іншому сервері сторінка редактора показує інструкцію запуску, без доступу до питань та редагування.

## Робота

- Оберіть тему або шукайте серед усіх питань. Картки показують весь пул відповідей, правильний варіант, пояснення та посилання на конспект.
- «Редагувати» відкриває форму. Радіокнопка визначає правильну відповідь; її попередній варіант стає неправильним. Мінімум — три неправильні варіанти, рекомендовано шість або більше. Регістр у відповідях враховується: паролі `hh03` та `HH03` різні.
- «Обрати фрагмент конспекту» відкриває список розділів із пошуком та переглядом. Можна також вставити посилання з іншого локального сервера або опублікованого конспекту: шлях і якір будуть перевірені.
- «Зберегти» записує файли, оновлює дані вікторини, лічильники та версії ресурсів. Незбережені правки не впливають на вікторину. Якщо файл змінився поза редактором, збереження буде відхилене, а форма залишиться відкритою.
- Нове питання має новий постійний ID. Редагування зберігає ID і статистику. Видалення потребує підтвердження; видаляти останнє питання теми не можна. Збережені результати минулих спроб не переписуються.
- Після серії змін перевірте `git diff` і зробіть коміт. Автоматичного коміту немає.

## Файли

Джерело даних — `questions.json` у каталозі кожної теми. `quiz-data.js` генерується командою `npm run build:quiz`; не редагуйте його вручну. Повна перевірка та збірка: `npm run build`. Серверні перевірки: `npm run test:admin`.

Підзаголовки конспектів мають сталі латинські `id`: при перейменуванні заголовка залишайте ID незмінним. `data-legacy-anchor` підтримує старі кириличні посилання.

Сервер слухає лише `127.0.0.1`, перевіряє Host/Origin і випадковий токен сеансу. Запис дозволений тільки в питання наявних тем і похідні файли збірки; довільних команд та шляхів API не приймає. Не виставляйте цей сервер через проксі або тунель у публічний доступ.
