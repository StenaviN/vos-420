8. Програмування HARRIS КХ RF-7800H-MP

Створення конфігурації RF-7800H-MP у CPA: передналаштування, ключі, канали, модеми, мережі FIX, HOP, ALE і 3G та перевірка готового плану.

Послідовність роботи

  1. Виконати передналаштування CPA.
  2. Створити ключі шифрування.
  3. Створити канали та канальні групи.
  4. Створити потрібні профілі модемів.
  5. Додати радіостанції й мережі до плану.
  6. Заповнити параметри мереж FIX, HOP, ALE і 3G.
  7. Перевірити план командою Validate Plan.
Принцип: спочатку створюють спільні ресурси плану, а потім призначають їх конкретним мережам. Ключ, канал, канальна група, модем або hopset мають уже існувати, щоб їх можна було вибрати у властивостях мережі.

Передналаштування CPA

Префікс назв радіостанцій

ToolsApplication Options
  1. У лівій частині вікна обери RF-7800H-MP.
  2. У розділі General введи потрібне значення в полі Name Prefix.

CPA використовуватиме цей префікс під час автоматичного формування назв нових радіостанцій.

Автоматичне створення TOD Mask

ToolsApplication OptionsHF Hopping

У полі Auto Generate TOD Mask встанови Enabled і підтвердь зміни кнопкою OK.

Ключі шифрування

ToolsKey ManagementKey Rings
  1. У вікні Key Manager обери Key Rings.
  2. Увімкни Enable Key Generation (Unrestricted Key Operation).
  3. Натисни Generate.
  4. Задай кількість у полі Number of Key Rings.
  5. Введи спільний початок назви в полі Key Ring Name Prefix.
  6. Обери потрібний алгоритм у групі Key Types.
  7. Натисни Generate і перевір створені ключі.
  8. Закрий Key Manager кнопкою Close.
Кількість, префікс і тип ключів визначає план зв'язку. Значення на скріншоті є прикладом, а не універсальними налаштуваннями.

Канали та канальні групи

Створення каналів

ToolsHF Channels
  1. У полі Channel Type обери режим, для якого створюєш канали: FIX, ALE, 3G або 3G+.
  2. Натисни Add для кожного потрібного каналу.
  3. Введи частоти приймання та передавання.
  4. Повтори операцію для інших потрібних режимів.
Для каналів 3G: у полі Max Bandwidth обов'язково встанови 24 kHz.
Для частот УКХ-діапазону понад 30 МГц: у полі Modulation Type встанови FM.

Створення канальних груп

Канальні групи потрібні для ALE та 3G. Для FIX і HOP їх не використовують.

  1. У частині Channel Groups натисни Add.
  2. Задай назву групи та обери її режим у полі Mode.
  3. Виділи канал у таблиці каналів і потрібну групу.
  4. Додай канал кнопкою Add праворуч або перетягни його до списку Member Channel.
  5. Натисни OK після заповнення груп.

Профілі модемів

ToolsHF Modem Presets
  1. Натисни Add.
  2. Задай назву профілю в полі Name.
  3. Обери модем у полі Type.
  4. Заповни параметри, доступні для обраного типу.

Для профілю WBHF вказати Bandwidth 24 kHz і Data Rate 120000 bps, тобто 120 кбіт/с.

Радіостанції та мережі

CreateCreate Networkтип мережі

Обери потрібний тип мережі: HF Fixed Frequency, HF Hopping, ALE або 3G.

Створення радіостанцій

Якщо це перша мережа плану:

  1. Обери тип RF-7800H-MP.
  2. Відкрий список біля New і вибери Create single RF-7800H-MP або Create multiple RF-7800H-MPs.
  3. Для створення кількох станцій введи потрібну кількість.
  4. Зніми виділення зі станцій натисканням на вільну область.
  5. Натисни Expand All, щоб відкрити параметри мережі.

Повторне використання станцій

Під час створення наступної мережі натисни Existing і додай до неї вже створені радіостанції. Одна станція може входити до кількох мереж плану.

Мережа FIX

CreateCreate NetworkHF Fixed Frequency

У правій панелі властивостей заповни:

  • Name — назва мережі;
  • Channel — канал, створений у Tools → HF Channels;
  • Crypto Algorithm — алгоритм шифрування;
  • Key Ring Name — створене кільце ключів;
  • Modem Preset — профіль модема;
  • CT Voice і PT Voice — вокодери для захищеного та відкритого режимів.

Мережа HOP

CreateCreate NetworkHF Hopping

Додай станції через Existing, зніми виділення та натисни Expand All.

Властивості мережі

Заповни основні властивості мережі:

  • Name — назва мережі;
  • Hopset — призначений набір частот;
  • Crypto Algorithm — алгоритм шифрування;
  • Key Ring Name — створене кільце ключів;
  • Modem Preset — профіль модема;
  • CT Voice і PT Voice — вокодери для захищеного та відкритого режимів.

Створення та модифікація hopset

  1. У групі Global HF Hopping відкрий HF Hopsets кнопкою з трьома крапками.
  2. Натисни Add, щоб створити новий hopset, або виділи наявний і натисни Modify. Кнопка Delete видаляє вибраний hopset.
  3. Заповни Name, Number і Type; перевір значення TOD Mask та Hopset ID.
  4. У полі Center Frequency задай центральну частоту.
  5. У полі Control (Auto Respond) Station обери головну станцію.
  6. Підтвердь налаштування кнопкою OK.

Мережа ALE

CreateCreate NetworkALE

Додай створені станції через Existing, зніми виділення та натисни Expand All. У властивостях мережі заповни:

  • Name — назва мережі;
  • Channel Group — канальна група ALE;
  • Crypto Algorithm і Key Ring Name — алгоритм та кільце ключів шифрування;
  • Modem Preset — профіль модема;
  • CT Voice і PT Voice — потрібні вокодери;
  • Use Default Self-Address — Enabled;
  • Link Protection — Disabled.

Мережа 3G

CreateCreate Network3G
  1. Додай радіостанції через Existing.
  2. Зніми виділення та натисни Expand All.
  3. Обери Crypto Algorithm і Key Ring Name.
  4. Відкрий поле 3G Configuration кнопкою з трьома крапками.

Конфігурація 3G

  • У групі 3G Preset обери Modem Preset, CT Voice і PT Voice.
  • У полі TOD Server обери головну радіостанцію, яка забезпечуватиме часову основу мережі.
  • У розділі Channel Plans задай назву кожного плану в полі Plan Name.
  • У полі Chan Group признач канальну групу 3G відповідному частотному плану.
  • Познач прапорцем Active частотний план, який має бути активним.

Перевірка плану

ActionsValidate Plan

Після завершення налаштувань виконай перевірку плану.

Переглянь результати перевірки та виправ помилки до використання конфігурації.

Повідомлення про режим шифрування SMS

Можливе повідомлення: Make sure your radio is in CT Mode or SMS will not work.

Повідомлення з'являється, коли для станцій параметр Station Cipher Mode має значення CT Only.

Рішення:

  1. Обери всі радіостанції плану.
  2. У панелі властивостей відкрий наведений шлях.
  3. Зміни Station Cipher Mode на PT/CT.
  4. Повторно виконай Actions → Validate Plan.

Програмування радіостанції через USB-кабель

Перегляд налаштування DIRECT USB та IP-адреси радіостанції

Перехід до програмування в CPA

  1. Після визначення IP-адреси радіостанції у панелі Navigator вибери потрібну станцію зі списку All Stations. На прикладі вибрано R1 типу RF-7800H-MP.
  2. Відкрий меню Actions → Program…. З’явиться вікно Radio Programming.
  3. Перевір Station Name і Radio Type: вони мають відповідати станції, яку програмуєш.
  4. У блоці Connection Type вибери Ethernet, а в полі Radio IP Address введи IP-адресу, визначену на радіостанції. Для підключення через DIRECT USB у цьому вікні використовується саме Ethernet.
  5. Перевір параметри запису в Programming Options. На прикладі позначено Program Radio Fill і Program Keys; Program CAM недоступний. Прапорець Set Radio TOD w/ System TOD на знімку вимкнений.
  6. Натисни Program, щоб розпочати програмування вибраної радіостанції.

Адреса 169.254.79.1 на знімку — приклад. У полі Radio IP Address потрібно вказати фактичну IP-адресу своєї радіостанції.
