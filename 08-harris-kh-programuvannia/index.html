Програмування Harris КХ

Створення конфігурації RF-7800H-MP у CPA: передналаштування, ключі, канали, модеми, мережі FIX, ALE, 3G і HOP та перевірка готового плану.

Послідовність роботи

  1. Виконати передналаштування CPA.
  2. Створити ключі шифрування.
  3. Створити канали та канальні групи.
  4. Створити потрібні профілі модемів.
  5. Додати радіостанції й мережі до плану.
  6. Заповнити параметри мереж FIX, ALE, 3G і HOP.
  7. Перевірити план командою Validate Plan.
Принцип: спочатку створюють спільні ресурси плану, а потім призначають їх конкретним мережам. Ключ, канал, канальна група, модем або hopset мають уже існувати, щоб їх можна було вибрати у властивостях мережі.

Передналаштування CPA

Префікс назв радіостанцій

ToolsApplication Options
  1. У лівій частині вікна обери RF-7800H-MP.
  2. У розділі General введи потрібне значення в полі Name Prefix.

CPA використовуватиме цей префікс під час автоматичного формування назв нових радіостанцій.

Автоматичне створення TOD Mask

ToolsApplication OptionsHF Hopping

У полі Auto Generate TOD Mask встанови Enabled і підтвердь зміни кнопкою OK.

Ключі шифрування

ToolsKey ManagementKey Rings
  1. Увімкни Enable Key Generation (Unrestricted Key Operation).
  2. Натисни Generate.
  3. Задай кількість у полі Number of Key Rings.
  4. Введи спільний початок назви в полі Key Ring Name Prefix.
  5. Обери потрібний алгоритм у групі Key Types.
  6. Натисни Generate, перевір створені ключі та закрий вікно.
Кількість, префікс і тип ключів визначає план зв'язку. Значення на скріншоті є прикладом, а не універсальними налаштуваннями.

Канали та канальні групи

Створення каналів

ToolsHF Channels
  1. У полі Channel Type обери режим, для якого створюєш канали: FIX, ALE або 3G.
  2. Натисни Add для кожного потрібного каналу.
  3. Введи частоти приймання та передавання.
  4. Повтори операцію для інших потрібних режимів.
Для каналів 3G: у полі Max Bandwidth обов'язково встанови 24 kHz.
Для частот УКХ-діапазону понад 30 МГц: у полі Modulation Type встанови FM.

Створення канальних груп

Канальні групи потрібні для ALE та 3G. Для FIX і HOP їх не використовують.

  1. У частині Channel Groups натисни Add.
  2. Задай назву групи та обери її режим у полі Mode.
  3. Виділи канал у таблиці каналів і потрібну групу.
  4. Додай канал кнопкою Add праворуч або перетягни його до списку Member Channel.
  5. Натисни OK після заповнення груп.

Профілі модемів

ToolsHF Modem Presets
  1. Натисни Add.
  2. Задай назву профілю в полі Name.
  3. Обери модем у полі Type.
  4. Заповни параметри, доступні для обраного типу.

Для профілю WBHF у презентації вказано Bandwidth 24 kHz і Data Rate 120000 bps, тобто 120 кбіт/с.

Радіостанції та мережі

CreateCreate Networkтип мережі

Обери потрібний тип мережі: HF Fixed Frequency, ALE, 3G або HF Hopping.

Створення радіостанцій

Якщо це перша мережа плану:

  1. Обери тип RF-7800H-MP.
  2. Відкрий список біля New і вибери Create Multiple.
  3. Введи потрібну кількість станцій.
  4. Зніми виділення зі станцій натисканням на вільну область.
  5. Натисни Expand All, щоб відкрити параметри мережі.

Повторне використання станцій

Під час створення наступної мережі натисни Existing і додай до неї вже створені радіостанції. Одна станція може входити до кількох мереж плану.

Мережа FIX

CreateCreate NetworkHF Fixed Frequency

У правій панелі властивостей заповни:

  • Name — назва мережі;
  • Channel — канал, створений у Tools → HF Channels;
  • Crypto Algorithm — алгоритм шифрування;
  • Key Name — створений ключ;
  • Modem Preset — профіль модема;
  • CT Voice і PT Voice — вокодери для захищеного та відкритого режимів.

Мережа ALE

CreateCreate NetworkALE

Додай створені станції через Existing, зніми виділення та натисни Expand All. У властивостях мережі заповни:

  • Name — назва мережі;
  • Channel Group — канальна група ALE;
  • Crypto Algorithm і Key Name — алгоритм та ключ шифрування;
  • Modem Preset — профіль модема;
  • CT Voice і PT Voice — потрібні вокодери;
  • Use Default self-address — Enabled.

Мережа 3G

CreateCreate Network3G
  1. Додай радіостанції через Existing.
  2. Зніми виділення та натисни Expand All.
  3. Обери Crypto Algorithm і Key Name.
  4. Відкрий поле 3G Configuration кнопкою з трьома крапками.

TOD Server і частотні плани

  • У полі TOD Server обери головну радіостанцію, яка забезпечуватиме часову основу мережі.
  • У розділі Channel Plans задай назву кожного плану в полі Plan Name.
  • У полі Chan Group признач канальну групу 3G відповідному частотному плану.

Мережа HOP

CreateCreate NetworkHF Hopping

Додай станції через Existing, зніми виділення та натисни Expand All.

Створення hopset

  1. У групі Global HF Hopping відкрий HF Hopsets кнопкою з трьома крапками.
  2. Для редагування наявного набору виділи його та натисни Modify.
  3. У полі Center Frequency задай центральну частоту.
  4. У полі Control (Auto Respond) Station обери головну станцію.
  5. Для створення інших наборів натисни Add і заповни ті самі основні поля.

Властивості мережі

Після створення hopset заповни Name, Hopset, Crypto Algorithm, Key Name, Modem Preset, CT Voice і PT Voice.
