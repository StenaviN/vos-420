Послідовність програмування

У CPS 2.0 спочатку читають конфігурацію радіостанції, потім налаштовують спільні параметри, ключі, контакти та списки. Після цього створені елементи призначають каналам і записують конфігурацію у радіостанцію.

  1. Зчитати конфігурацію та визначити потрібну операцію: запис або клонування.
  2. Задати псевдонім та ID радіостанції, паролі й функції кнопок.
  3. Створити потрібні ключі AES-256 та RAS; за потреби налаштувати TLS-PSK.
  4. Створити цифрові контакти й списки груп RX.
  5. Додати зони та канали; призначити частоти, контакт, список RX, колірний код, таймслот і ключі.
  6. Налаштувати сканування та потрібні додаткові функції.
  7. Записати конфігурацію та перевірити результат на радіостанції.
У цьому конспекті файл конфігурації (codeplug) — це набір налаштувань радіостанції. Слово «прошивка» в навчальних прикладах використано для цього файла; описані операції не є процедурою оновлення мікропрограмного забезпечення.

Команда CPS Що виконує

Записати Записує конфігурацію в ту радіостанцію, з якої її зчитали.
Клонувати Переносить конфігурацію в радіостанцію тієї самої моделі.
Експрес-клонування Переносить конфігурацію в радіостанцію тієї самої моделі, зберігаючи її ID та псевдонім.

Псевдонім та ID радіостанції

ЗагальнеЗагальні параметри

У полі «Псевдонім радіо» задають назву радіостанції, а в полі «ІД радіостанції» — її ідентифікатор. Для приватного контакту іншої радіостанції використовується саме ID потрібного кореспондента.

Паролі конфігурації та ввімкнення

ЗагальнеЗагальні параметри

Пароль на зчитування

Ввести пароль у поле «Пароль Codeplug». Для поля «Перевірити наявність пароля» вибрати «Лише для читання».

Пароль на ввімкнення

У розділі «Пароль і блокування» позначити «Увімкнути» та заповнити поле «Пароль». Це окреме налаштування від пароля зчитування конфігурації.

Призначення кнопок

ЗагальнеКнопки керування

Вибрати потрібну кнопку й призначити їй дію. У CPS окремо показані налаштування короткого та довгого натискання. Список доступних кнопок і функцій залежить від моделі.

Ключі AES-256

ЗагальнеБезпека
Шифрування — AES-256. 40-бітний захист не рекомендований до використання. Подальші налаштування шифрування в цьому конспекті виконуються з AES-256. Поля «Конфіденційність» і «Псевдонім конфіденційності» на старих знімках стосуються 40-бітного захисту; їх не слід використовувати замість симетричного ключа AES-256.

Створення ключів AES-256

Ключі AES-256 створюють у розділі «Симетричний». У матеріалі зазначено: до 32 ключів, максимальний ID ключа — 255. Для призначення AES-256 каналу потрібна відповідна ліцензія на радіостанції.

Ключі RAS

ЗагальнеБезпекаОбмежений доступ до системи (RAS)

Для роботи через ретранслятор створити ключ RAS: заповнити його псевдонім та поле «Значення ключа». Довжина ключа — 6–24 символи; у конфігурації можна створити до 16 ключів.

Після створення ключ потрібно призначити каналу в полі «Псевдонім RAS». Сам запис у списку ключів ще не означає, що його використовує потрібний канал.

Автентифікація TLS-PSK

За матеріалом, обладнання MOTOTRBO з версією вище R02.10.5 підтримує TLS-PSK. Функція передбачає додатковий пароль у CPS 2.0 та в налаштуваннях захисту обладнання. Вона захищає від несанкціонованого запису, клонування та відновлення заводських налаштувань; застосовується під час роботи через USB, Ethernet і радіоефір.

  1. Відкрити керування попередньо наданими ключами в CPS та додати потрібний ключ.
  2. Відкрити розділ TLS-PSK у налаштуваннях безпеки радіостанції та вибрати відповідний ключ.
ІнструментиКерування попередньо наданими ключами…
ЗагальнеБезпекаTLS-PSK автентифікація
Застереження з навчального матеріалу: втрата пароля TLS-PSK може унеможливити відновлення обладнання; у презентації це сформульовано як «обладнання відновленню не підлягає». Пароль потрібно зберегти до активації функції.

Цифрові контакти

КонтактиКонтакти

У конфігурації вже можуть бути стандартні контакти. Для нової мережі створюють окремий цифровий контакт.

  1. Натиснути «+» над списком контактів.
  2. Натиснути «+» біля категорії «Цифровий».
  3. Вибрати тип: груповий або приватний виклик.
  4. У полі «Контакт» задати назву. Для групового контакту в полі «ID виклику» вказати ідентифікатор групи.
  5. Перевірити появу контакту в загальному списку.

Список груп RX

Списки груп RXСписок груп цифрового RX
  1. Створити новий список або відредагувати наявний, якщо він більше не потрібен для іншого призначення.
  2. Додати раніше створений груповий контакт у праву колонку учасників.
  3. Назвати список зрозуміло; у прикладі його назва збігається з назвою контакту.

Цей список далі вибирають у параметрах приймання каналу — поле «Список груп».

Зони та створення каналів

Призначення зон/каналівЗонаZone 1

Відкрити потрібну зону. Для нового каналу натиснути «+» та вибрати тип — цифровий або аналоговий. Для редагування наявного каналу виділити його й натиснути кнопку із зображенням олівця.

Основні параметри цифрового каналу

Поле Що задають
Назва каналу Назву, за якою користувач розпізнає канал.
Список сканування/роумінгу Раніше створений список для цього каналу.
Колірний код Колірний код мережі.
Слот повторювача/часу Таймслот каналу.

Значення на знімках — приклад конфігурації. Частоти, ID, колірний код, таймслот і ключі задаються для конкретної мережі.

AES-256 на каналі

Якщо радіостанція має ліцензію AES-256, вибрати ключ у полі «Симетричний псевдонім». Прапорець «Конфіденційність» при цьому зняти.

Вибір ключа «Випадково»

У списку симетричних ключів каналу вибрати «Випадково». Для цієї функції потрібні щонайменше два ключі AES-256. У розділі «Безпека → Загальне» зняти прапорець «Виправлено дешифрування ключа захисту конфіденційності», як показано в матеріалі.

RAS на каналі

Для каналу через ретранслятор вибрати раніше створений ключ у полі «Псевдонім RAS».

Розділ Поля

Критерії доступу «Критерій прийнятності» та «Критерії вхідного виклику». У базовому прикладі — «Без колірного коду» та «Відповідно до критеріїв прийнятності».

Канал через ретранслятор

У наведеній конфігурації канал розпізнається як ретрансляторний, коли частоти приймання та передавання різні. Для такого каналу матеріал вказує ввімкнути поле з назвою «Дозволити гучний зв’язок».

Сканування каналів

Списки скануванняЕлементи сканування
  1. Створити новий список або відредагувати непотрібний старий.
  2. Додати потрібні канали до правої колонки учасників.
  3. Дати списку зрозумілу назву.
  4. Повернутися до каналу, з якого виконуватиметься сканування, та вибрати цей список у полі «Список сканування/роумінгу».

Вимкнення індикації та звуків

ЗагальнеЗагальні параметри

Для вимкнення світлової індикації позначити «Вимкнути всі LED-індикатори». Для вимкнення звуків перейти до розділу «Сигнали» та позначити «Вимкнути всі звуки».

Текстове повідомлення за кнопкою

ЗагальнеТекстові повідомлення
  1. Створити текст повідомлення.
  2. Відкрити «Загальне → Кнопки керування → Доступ за один дотик».
  3. У потрібному рядку заповнити контакт у полі «Виклик», вибрати «Тип виклику → Текстове повідомлення» та потрібний текст.
  4. Призначити кнопці дію «Доступ за один дотик» із номером відповідного рядка.

Копіювання між різними моделями

Для перенесення налаштувань між різними моделями, наприклад DP4800 та DP4400, у матеріалі використано копіювання вузла «Конфігурація».

  1. У конфігурації вихідної радіостанції натиснути правою кнопкою на «Конфігурація» та вибрати «Копіювати».
  2. Відкрити конфігурацію радіостанції іншої моделі, натиснути правою кнопкою на «Конфігурація» та вибрати «Вставити».
  3. Перевірити перенесення ключів, контактів і каналів; за потреби виправити параметри.

Це окрема процедура: команда «Клонувати» на верхній панелі описана для радіостанцій тієї самої моделі.

Віддалене керування та захист

СистемиСистеми сигналізації

Щоб вимкнути можливість віддаленого моніторингу та блокування радіостанції, у розділі «Цифровий» прибрати відповідні прапорці декодування віддаленого моніторингу й деактивації.

У наведеному витягу з настанови запропоновано два варіанти захисту від неавторизованого блокування: вимкнути «Декодування деактивації радіостанції» або, якщо модель підтримує цю функцію, використовувати автентифіковане блокування/розблокування з автентифікацією користувача та встановленим паролем чи кодовою фразою.

Пункти меню керування іншою радіостанцією

ЗагальнеМенюКонтакти

На радіостанціях з екраном потрібні пункти віддаленого керування вмикають прапорцями в розділі «Контакти». Їхня наявність у меню не замінює налаштувань дозволів та автентифікації керованої радіостанції.

Приватний контакт та індивідуальний виклик

КонтактиКонтакти
  1. Натиснути «+» над списком контактів, потім «+» біля «Цифровий».
  2. Вибрати «Приватний виклик» та натиснути OK.
  3. У поле «Контакт» записати ім’я або позивний кореспондента.
  4. У поле «ID виклику» записати ID радіостанції кореспондента, а не номер групи.

Перевірка на DP4800

Після запису конфігурації натиснути OK, відкрити Contacts / Контакти, підтвердити OK та знайти створений контакт. Перевірити його ім’я й номер. Для виклику вибраного кореспондента натиснути PTT.
