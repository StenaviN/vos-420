Меню RF-7800H-MP

Експериментальна карта меню передньої панелі для прошивки 2.x. Склад пунктів залежить від установлених опцій, активної форми сигналу та вибраного пресета.

Звичайний пункт меню Умовний пункт Натисни назву гілки, щоб розгорнути її.

7 OPT Меню параметрів

Пункти верхнього рівня відображаються за абеткою. Гілки ALE, 3G, HOP та інші параметри форми сигналу з'являються лише для відповідного пресета.

ALEпараметри ALE
  • LQA: EXCHANGE, SOUND, SCORES
  • Доступність пунктів залежить від активного ALE-пресета.
3Gпараметри 3G
  • Параметри викликів, синхронізації та роботи 3G.
  • Відображається для активного 3G-пресета.
COUPLER OPTIONSантенний узгоджувач
  • Параметри вбудованого або підключеного антенного узгоджувача.
GPS OPTIONSстан і параметри GPS
  • Перегляд стану GPS та доступних супутникових даних.
HOPпараметри HOP
  • Синхронізація та службові параметри активного HOP-пресета.
  • Відображається лише в режимі HOP.
LOCKблокування органів керування
  • KEYPAD
  • SECURE
LQAоцінювання каналів
  • EXCHANGE → адреса станції
  • SOUND → SOUNDING
  • SCORES → REVIEW → INDIVIDUAL ADDRESS
  • SCORES → ZEROIZE SCORES → ZEROIZE ALL SCORES → YES | NO
MESSAGINGтекстові й голосові повідомлення
  • SMS: створення, передавання, приймання та видалення повідомлень.
  • LDV: перегляд і відтворення отриманих голосових повідомлень.
  • Доступні гілки залежать від активної форми сигналу.
MISSION PLANплан місії
  • ACTIVATE MISSION PLAN → MISSION PLAN FILE → файл → ACTIVATE PLAN → NO | YES
  • MISSION PLAN HISTORY
NETWORK OPTIONSмережеві інструменти
  • SEND PING → HOST NAME | IP ADDRESS
  • INTERFACES → VIEW INTERFACE INFORMATION
  • VOIP CONFIG → VOIP GENERAL CONFIG
  • INTERCOM CONFIG → режим, IP-адреса, порт
  • SIP CONFIG → режим, автовідхилення, номер, підказки, сигнал виклику
RADIO INFORMATIONстан радіостанції
  • SYSTEM CLOCK → дата, час, UTC OFFSET
  • BATTERY INFORMATION → напруга і стан → ресурс HUB
RADIO OPTIONSоперативні параметри
  • RADIO SILENCE → OFF | ON
  • PRESET AUTOSAVE
  • SQUELCH LEVEL → HIGH | MED | LOW
  • BFO → вибір зміщення частоти
  • RX NOISE BLANKING → OFF | ON
  • RF FAULTS PERSIST → ON | MOMENTARY
  • PA FAILSAFE OVR → DISABLED | ENABLED
  • REMOTE KDU → DISABLED | FALCON II/III KDU | SOFT KDU
SHORTCUT KEYSшвидкі клавіші
  • Призначення та перегляд дій, доступних через клавіші швидкого виклику.
SYSTEM INFORMATIONслужбова інформація
  • SYSTEM SERIAL NUMBER
  • ELAPSED TIME: HOURS UP, HOURS TX, TIMES KEYED
  • PART NUMBER
  • TCXO TUNING
TEST OPTIONSтестування
  • SELF TEST → RUN SELF TEST → NO | YES
  • LCD TEST
  • KEYPAD TEST
  • Додаткові модульні тести залежать від комплектації радіостанції.
TX POWER OPTIONSпотужність передавача
  • TX POWER LEVEL → HIGH | MEDIUM | LOW | USER
VIEW KEY INFOперегляд завантажених ключів
  • Вибір форми сигналу та перегляд доступної інформації про ключі.

8 PGM Меню програмування

Меню доступне в положеннях перемикача PT і CT. Після приблизно п'яти хвилин без натискання клавіш станція повертається до звичайної роботи.

RADIO CONFIGзагальні параметри станції
CHANGE MAINTENANCE PASSWORDпароль обслуговування
  • Зміна пароля, потрібного для захищених операцій технічного обслуговування.
GENERAL CONFIGзагальні налаштування
  • AUDIO CONFIG
  • AUTOSAVE CONFIG
  • BATTERY CONFIG → модель батареї
  • CITADEL/AES CONFIG → AKS, CAM, ключі
  • CT OVERRIDE CONFIG
  • DATA PORT CONFIG
  • EXTERNAL DEVICE
  • EXTERNAL KEYLINE
  • GPS CONFIG
  • MESSAGING CONFIG
  • NETWORK CONFIG
  • PORT CONFIG
  • SHORTCUT KEYS CONFIG
SYSTEM CLOCKчас і дата
  • Формат дати й часу, часовий пояс та параметри синхронізації.
MAINTENANCEтехнічне обслуговування
  • Скидання HUB, заводські налаштування та інші захищені службові операції.
SYSTEM PRESETSсистемні пресети
SYSTEM PRESET CONFIGналаштування пресета
  • SYSTEM PRESET NUMBER
  • PRESET DESCRIPTION
  • PRESET WAVEFORM → HF | WBHF
  • GENERAL CONFIG → назва, режим, канал, модем, шифрування, голос
HF CONFIGканали та режими КХ
CHANNELканали
  • EDIT CHANNEL → частоти RX/TX
  • MODULATION → USB | LSB | AME | CW
  • AGC SPEED
  • IF BANDWIDTH
  • RX ONLY
  • LIMIT MAX TX POWER
  • MAX BANDWIDTH → 3–24 kHz
MODEMпресети модемів
  • MODEM PRESET → назва
  • ARQ PROTOCOL → NONE | 1052
  • MODEM TYPE → MIL 110B | WBHF | SERIAL
  • BANDWIDTH, DATA RATE, INTERLEAVE, PREAMBLE
ALEадреси, групи каналів і параметри ALE
  • Канальні групи, власні, індивідуальні та мережеві адреси, конфігурація ALE.
HOPхопсети й параметри HOP
  • Канали HOP, тип хопсета, ідентифікатор, TOD Mask та станція керування.
VULOS CONFIGопційна форма сигналу
  • Відображається, якщо відповідну форму сигналу встановлено й дозволено.
WBHF CONFIGширокосмугові режими
  • Параметри 3G, 3G+ та інших установлених широкосмугових можливостей.
